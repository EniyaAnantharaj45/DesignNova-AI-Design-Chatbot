# DesignNova – AI-Powered Design Chatbot

## About the Project
DesignNova is an AI-powered design chatbot that helps users create different designs using text prompts.

## Features
- Generate posters
- Create presentation designs
- Design websites
- Generate logos
- Create resumes

## Technologies Used
- HTML
- CSS
- JavaScript
- AI Integration

## Project Purpose
The main goal of DesignNova is to make the design creation process easier and faster through AI.
