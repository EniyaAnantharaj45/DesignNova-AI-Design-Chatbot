Architecture & Creative Generation Capabilities

System: DesignNova AI All-in-One Design Assistant

DesignNova AI is a unified creative platform. Instead of merely outputting plain descriptive text, it understands user intentions and produces actual interactive outputs (resumes, portfolios, logos, posters, web prototypes, slides, and code) with live previews and real downloads (PDF, PPTX, PNG, SVG, ZIP, and HTML).

8 in 1 Creative Superpowers
Real Files PDF, PPTX, SVG, PNG, ZIP
Live Sandboxes Interactive Previews
  • AI Resume Builder: Collects user credentials, generates professional resume previews, supports 4 templates, and enables instant PDF download.
  • AI Portfolio Builder: Generates multi-section responsive portfolio websites with live device sandboxes and ZIP bundle downloads.
  • AI Logo Designer: Generates vector geometric and typography logos with SVG and 1200x1200px PNG exports.
  • Poster, Banner & Invite Designer: Creates event artwork with custom aspect ratios, rich typography, and PNG/PDF export.
  • Website & UI/UX Designer: Generates interactive HTML/CSS/JS landing pages and prototypes with desktop/tablet/mobile toggles.
  • PPT & Document Creator: Formats multi-slide decks with slide carousels and native Microsoft PowerPoint (.pptx) download.
  • Code Generator & Sandbox: Generates HTML, CSS, JS, Python, and Java with one-click copy and live web execution.
  • General AI Chat: Answers design questions, performs UX audits, and recommends color and typography systems.
html2pdf.js Client-side HTML5 canvas rendering to high-resolution print-ready PDF documents for resumes and posters.
PptxGenJS Generates real, editable Microsoft PowerPoint presentations (.pptx) directly in the browser with custom slide layouts.
JSZip Packages complete multi-file web portfolios (index.html, style.css, script.js) into compressed .zip archives for download.
Modern CSS3 & Canvas High-DPI HTML5 Canvas rasterization for logos and posters, CSS custom properties, and responsive viewports.
Q: How do I configure my own AI API key? A: Copy .env.example to .env in the project folder and paste your key (e.g. OPENAI_API_KEY=sk-... or GEMINI_API_KEY=...). The Node backend automatically loads it securely via process.env without exposing it to the browser.
Q: Does DesignNova AI work without an API key? A: Yes! DesignNova includes a comprehensive built-in generation engine for all 8 tools, so resumes, portfolios, logos, posters, prototypes, slides, and code generate immediately with zero setup.
